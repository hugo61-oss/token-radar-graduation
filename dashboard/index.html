How the model works

Every figure comes from the sealed snapshot alone. No protocol name is special-cased.

  • Peer-implied token value = TVL × peer multiple. The peer multiple is the median market-cap-per-TVL of tokenized protocols in the same category, shrunk toward the global median when the category has few tokenized peers; each peer's multiple is capped at 5x first, so a tiny-TVL protocol's extreme ratio cannot carry a whole category.
  • Graduation probability = logistic(size, growth, age, reach, category prior). Size is log TVL, growth is the 7-day TVL change, age is days listed with no token recorded, reach is the number of chains, and the prior is how often this category's protocols record a token in this snapshot.
  • Expected value = probability × peer-implied token value. That is the board's rank.
  • Months to token = 3 + 33 × (1 − probability): a read-out of the probability, not a separate forecast.

A protocol is called pre-token when its record carries no token: no market cap, no CoinGecko id, no symbol. That is what the record says, never proof it has no token. Protocols that structurally never launch their own token — exchanges, bridges, staking wrappers, versioned pools — are screened out of the ranking, except that every watchlist protocol is always ranked.
